데이터 분석가로 취업을 위해서는 무엇을 해야 할까? 아직 나도 취준생이니까 정답을 모르지만(...), 주변에서 들은 이야기와 job description(JD)를 종합한 결과 아래와 같다.

- 데이터로 문제 정의 및 해결을 한 과정을 보여주는 포트폴리오
- 분석 프레임워크(AARRR 등)에 대한 이해
- SQL
- 통계학적 지식 (+ 머신러닝 관련 지식..?)
- Python
  - "Python"이라고 하면 조금 포괄적인 느낌이 있지만.. 이 부분 관련해서는 회사마다, 또 포지션마다 기대하는 수준이 다양한 것 같다.

또한, 내가 목표하는 회사 중 여러 곳이 SQL 코딩 테스트를 진행함을 알게 되었다.

학부생 시절 '데이터베이스' 과목을 수강했지만, 이때가 SQL과의 만남의 끝이었다. 이후 회사에 다니면서 아주 간혹 SQL을 쓸 일이 있었지만, DBA와 함께 테이블을 생성하거나 간단한 SQL로 값을 update하는 게 끝이었다.

그래서 SQL 코딩 테스트를 위해서 SQL 관련 복습 및 문제 풀이를 시작했다. 처음에는 혼자서 쉬운 문제 위주로 복습하려고 했지만, 한번 체계적으로 정리해 보고자 강의를 듣기로 하였다. 그리고 데이터리안 강의를 만나게 되었다! 내가 데이터리안 강의를 고른 이유는 다음과 같다.
- **SQL을 익히기 위해 필수적인 내용 위주로 구성되어 있다.**
- **강의에서 배운 내용을 바로 연습할 수 있는 문제 풀이가 함께 있다.**
- **SQL 문법을 배우는 것에서 끝나는 게 아니라, 배운 SQL 문법을 분석 프레임워크에도 적용해 볼 수 있다.**

통계학을 전공하였지만, job description(JD)에 기술된 분석 프레임워크를 학교에서 접할 일은 거의 없어서 고민 중이었는데, SQL을 활용해서 분석 프레임워크까지 실습해 볼 수 있다니! 마음에 아주 쏙 들었다.

수강을 결심한 후 입문반부터 들은 후에 실전반을 들을지, 바로 실전반을 들을지 고민하였는데, SQL의 기초 문법을 확실히 정리하고 싶었고, RFM 분석 프레임워크와 기본적인 매출 분석 내용을 익히고 싶었기 때문에 입문반부터 신청하였다. 이 부분이 고민된다면 [데이터리안에서 제공하는 짧은 레벨테스트](https://datarian.io/blog/sql-camp-level-test)가 있으니 이걸 응시하는 것도 추천한다!

실제로 수업을 들으면서 기대했던 부분들이 모두 충족되었다.
- **SQL을 익히기 위해 필수적인 내용 위주로 구성되어 있다. ✅**
  - 데이터 분석가 실무자분들께서 강의를 해주셔서 그런지 실무에서 필요한 내용 위주로 가르쳐주신다. 그렇다고 내용이 빈약한 것이 아니라, 중요한 내용이 잘 정리되어서 담겨있다!
  - 실무 팁을 주신 부분도 좋았다!
- **강의에서 배운 내용을 바로 연습할 수 있는 문제 풀이가 함께 있다. ✅**
  - 주차별 추가 연습문제가 있어서 배운 내용을 바로 연습할 수 있었다.
- **SQL 문법을 배우는 것에서 끝나는 게 아니라, 배운 SQL 문법을 분석 프레임워크에도 적용해 볼 수 있다. ✅**
  - RFM 분석 등의 분석 프레임워크를 SQL로 실습해 본 부분도 매우 좋았다.

추가적으로 다음 장점들도 있었다.
- **실습환경이 잘 되어있다.**
  - SQL을 연습하기 위해서 로컬에 데이터베이스를 설치해야 하는 경우가 종종 있고, 여기서부터 쉽지 않을 수 있다. 그렇지만 데이터리안에서는 solvesql이라는 플랫폼을 사용하기 때문에 인터넷만 되는 환경이라면 로컬 환경에 별도로 데이터베이스를 설치하지 않고서 바로 실습할 수 있었다.
  - solvesql 플랫폼에는 수업에서 사용하는 데이터셋뿐만 아니라, 프로젝트 추천 데이터셋도 업로드되어 있어서 SQL 실습을 하기에 매우 편리했다.
- **수강생이 데이터 분석 프로젝트를 시작할 수 있도록 상세한 가이드가 제공된다.**
  - 데이터리안 수업에서 개인 프로젝트는 각자 진행하는 사이드 프로젝트처럼 진행된다. 그렇지만 각자 데이터 분석 프로젝트를 시작할 수 있도록 프로젝트 관련된 개괄적인 내용부터 수업에서 배운 내용을 바탕으로 어떻게 프로젝트를 하면 좋을지에 대한 구체적인 아이디어 및 다양한 레퍼런스들을 공유해 주신다.
    - 혼자서 프로젝트를 진행하기 어렵거나 여럿이 모여 집단지성으로 프로젝트를 완성하고 싶을 경우, 데이터리안 슬랙 내에서 프로젝트 팀원도 구할 수 있다!
  - 추가적으로, 완강 이후에도 슬랙에 각자 완성한 프로젝트를 올리면 하나하나 피드백을 달아주신다! 이 부분이 정말 큰 장점이라고 생각한다.
- **슬랙으로 질의응답을 할 수 있다.**
  - 수강생 대상 슬랙이 운영되기 때문에 구글링해도 헷갈리는 부분 등을 쉽게 질문할 수 있었다.
